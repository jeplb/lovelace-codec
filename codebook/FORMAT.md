# Lovelace image format v1 — NOT APPROVED FOR SYNTHESIS

Selected S12: 256 complex coefficients, each real then imaginary as a six-bit unsigned quantizer label, row-major across the 16x16 crop. Bits concatenate most-significant first, forming exactly 384 bytes per image. Physical digits take successive pairs of bits MSB first. State digits 0..3 map respectively to (3,7,10),(3,10,7),(7,3,10),(7,10,3), always A then C then T. No entropy coding or outer correction.

Each image has a 64-byte big-endian header, struct >4sBBBBBBHddI32s. Offsets: 0 magic LVIM (4); 4 version 1 (1); 5 height 32 (1); 6 width 32 (1); 7 retained height 16 (1); 8 retained width 16 (1); 9 component bits 6 (1); 10 flags 1 (2); 12 mean float64 (8); 20 scale float64 (8); 28 payload bytes 384 (4); 32 SHA256 (32). Digest covers the preceding 32-byte prefix plus payload, so mean and scale are integrity-checked. Digest is recovered from strands, never supplied as expected truth. Bounds are checked before reconstruction; no source reference is used to repair headers.

Header then payload =448 bytes/image=224 two-byte oligos. Global addresses 0..223=image A, 224..447=image B, 448..471=fit pilots, 472..479=QC pilots; 480..2047 unused. Image identity and byte offset come solely from decoded global addresses. Header is not independently repeated or protected. Both images share the same 32 pilots; each pilot i has cell j digit (i+j) mod4.

Address: extended Hamming(16,11), parity positions 1,2,4,8 among 1..15, overall parity position16. Message bits LSB-first fill ascending nonparity positions. Word bit0 corresponds position1; XOR 0xF6CF. Starting implicit A, each transmitted bit advances ACT cycle by +1 for zero or +2 for one. Expand each of 16 symbols fivefold. This is the existing address code, not a payload correction layer. Minimum binary Hamming distance4 is not a DNA edit guarantee.

Forward strand: CCCAATTAATACGTTGCCTACTCCG + address80 + GGGG + eight composition cells160 + GGGG + CGCTATCAGAACAAGAGAAGCACTA. Ordered reverse primer is TAGTGCTTCTCTTGTTCTGATAGCG. All strands298nt. 480 strands=143,040 designed nucleotides; 9,536 are pilots. Exact attempted counts at depth8/16/32/64:3,840/7,680/15,360/30,720. All rejected/chimeric/pilot reads count. No noised-input regeneration is needed to replay a saved decode.

Inverse image: map labels to endpoint-inclusive uniform [-s,s]; zero-fill full 32x32 shifted Fourier grid except slice[8:24,8:24]; ifftshift then unitary ifft2; real part plus mean. The crop lacks complete Hermitian boundary pairs: imaginary RMS is reported, not silently assumed zero. No clipping, gain normalization or post-reconstruction enhancement. For visual display only, fixed gray range[0,1] saturates outside values; metrics use all unmodified float64 values.
